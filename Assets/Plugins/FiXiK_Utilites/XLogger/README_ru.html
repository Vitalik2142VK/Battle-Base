XLogger

Версия 1.0.1 | Автор: FiXiK | 6 сентября 2026

Editor & Runtime Conditional Logging Tag System Custom Colors

XLogger — это гибкая система логирования для Unity, позволяющая:

  • Выводить логи с тегами, цветами и стилями шрифта.
  • Настраивать внешний вид сообщений (Log, Warning, Error) через редактор.
  • Автоматически генерировать перечисление TagType и структуру LogColor на основе настроек.
  • Условное логирование (condition) и удаление логов в релизных билдах.
  • Поддержка многострочных сообщений с сохранением форматирования.
  • Полная локализация интерфейса (русский/английский).

Возможности

  • Гибкий билдер – цепочка методов .WithColor(), .WithTag(), .WithLogType() и др.
  • Система тегов – каждый тег имеет свой цвет и имя, которые можно редактировать.
  • Генерация кода – при сохранении настроек автоматически создаются файлы TagType.cs и LogColor.cs.
  • Условная компиляция – все методы логирования удаляются в релизных билдах.
  • Очистка консоли – метод XLogger.ClearConsole() работает только в редакторе.
  • Настройки через ScriptableObject – все параметры хранятся в LoggerSettings.asset, доступны через окно Tools/XLogger/Settings.
  • Локализация – переключение языка интерфейса настроек.
  • Корректный double-click – клик по логу в Console всегда открывает вызывающий код.

Установка

Через .unitypackage (рекомендуется)

  1. Скачайте последний релиз.
  2. Импортируйте .unitypackage через Assets → Import Package → Custom Package.
  3. Готово! Плагин автоматически создаст файл настроек и покажет приветственное окно.

Ручная установка

  1. Скопируйте папку XLogger в любое удобное место внутри Assets.
  2. Перезагрузите Unity (или нажмите Ctrl+R).
  3. Откройте окно настроек через Tools → XLogger → Settings.

Быстрый старт

  1. Откройте окно настройки
    Tools → XLogger → Settings
  2. Настройте теги
    В разделе Tag Settings добавьте/удалите теги, укажите цвета.
  3. Настройте цвета сообщений
    В разделе Message Settings выберите цвет и стиль для Log, Warning, Error.
  4. Добавьте кастомные цвета
    В разделе Color Settings определите свои именованные цвета (будут доступны как LogColor.YourColor).
  5. Сохраните
    Нажмите Save Settings – будут сгенерированы файлы TagType.cs и LogColor.cs.
  6. Используйте в коде
    // Простые логи
XLogger.Log("Hello");
XLogger.LogWarning("Warning");
XLogger.LogError("Error");

// Гибкий вариант
XLogger.Message("Многострочное\nсообщение")
    .WithColor(LogColor.Cyan)
    .WithFontStyle(FontStyle.Bold)
    .WithTag(TagType.INPUT)
    .WithLogType(XLogType.LogWarning)
    .Log();

// Условный лог
XLogger.Log("Это выведется только если condition == true", condition);

Настройка через редактор

Все настройки хранятся в файле LoggerSettings.asset, который автоматически создаётся в папке Resources рядом с плагином.

Вы можете редактировать его вручную через инспектор Unity или через окно настроек.

Секции настроек

  • Tag Settings – включение отображения тегов, тег по умолчанию, список пользовательских тегов.
  • Message Settings – цвета и стили для Log, LogWarning, LogError.
  • Color Settings – список именованных цветов (имя → цвет), которые будут доступны в структуре LogColor.

API (для разработчиков)

Основные методы XLogger

// Простые методы
public static void Log(object message, bool condition = true);
public static void LogWarning(object message, bool condition = true);
public static void LogError(object message, bool condition = true);

// Расширенные методы (с контекстом, цветом, стилем, тегом)
public static void Log(object message, Object context, bool condition = true);
public static void Log(object message, Color32 color, bool condition = true);
public static void Log(object message, TagType tag, bool condition = true);
// ... и другие комбинации

// Билдер для гибкой настройки
public static MessageInfo Message(object message);

Билдер MessageInfo

XLogger.Message("текст")
    .WithColor(Color32 color)                 // устанавливает цвет
    .WithFontStyle(FontStyle style)           // Normal/Bold/Italic/BoldAndItalic
    .WithTag(TagType tag)                     // устанавливает тег
    .WithLogType(XLogType type)               // Log / LogWarning / LogError
    .WithContext(Object context)              // контекст для подсветки в редакторе
    .WithCondition(bool condition)            // условный вывод
    .Log();                                   // отправляет сообщение

Генерация кода

При сохранении настроек автоматически генерируются:

  • TagType.cs – перечисление всех тегов (первый элемент всегда LOGGER = 0).
  • LogColor.cs – структура со статическими свойствами Color32 для каждого цвета.

Поведение в билдах

  • Все методы XLogger.Log* и Message(...).Log() — удаляются в релизных билдах (без DEVELOPMENT_BUILD). В редакторе и Development-билдах работают.
  • Метод XLogger.ClearConsole() — работает только в редакторе.

Важно: В релизных билдах логирование полностью отключено. Это сделано намеренно для производительности.

Требования

  • Unity 2020.3 или новее (проверено на 2021.3 LTS, 2022.3, 2023.2).
  • Платформа: любая, поддерживающая редактор Unity (Windows, macOS, Linux).
  • Зависимости: отсутствуют.

Часто задаваемые вопросы

Вопрос: Почему мои логи не выводятся в билде?
Ответ: Все методы логирования удаляются условной компиляцией в релизных билдах. Это сделано для производительности.
Вопрос: Как добавить новый тег?
Ответ: Откройте окно настроек (Tools/XLogger/Settings), в разделе Tag Settings нажмите + в поле Tags, введите имя и выберите цвет. Нажмите Save Settings – тег появится в перечислении TagType.
Вопрос: Как добавить свой цвет в LogColor?
Ответ: В окне настроек, в разделе Color Settings, добавьте новый элемент, укажите имя и цвет. При сохранении в LogColor появится статическое свойство с этим именем.
Вопрос: Почему тег не отображается в сообщении?
Ответ: Проверьте, включена ли опция Show Tag в настройках (раздел Tag Settings). Также убедитесь, что вы передали тег через .WithTag().
Вопрос: Можно ли использовать LogColor вне логгера?
Ответ: Да, LogColor – это обычная структура с цветами, её можно использовать где угодно в коде.
Вопрос: Как переключить язык интерфейса?
Ответ: В окне настроек есть выпадающий список в самом верху – выберите English или Русский. Выбор сохраняется в EditorPrefs.
Вопрос: Есть ли конфликт с UnityEngine.Logger?
Ответ: Нет, XLogger – это уникальное имя, которое не конфликтует со встроенным логгером Unity.
Вопрос: Почему при двойном клике по логу открывается не мой код?
Ответ: В версии 1.0.1 эта проблема исправлена. Убедитесь, что используете актуальный релиз. Также рекомендуется включить Strip logging callstack в окне Console (⋮ → Strip logging callstack).
