XLogger

Version 1.0.1 | Author: FiXiK | September 6, 2026

Editor & Runtime Conditional Logging Tag System Custom Colors

XLogger is a flexible logging system for Unity that allows you to:

  • Output logs with tags, colors, and font styles.
  • Customize the appearance of messages (Log, Warning, Error) through the editor.
  • Automatically generate the TagType enum and LogColor structure based on settings.
  • Use conditional logging (condition) and strip logs from release builds.
  • Support multi-line messages while preserving formatting.
  • Fully localized settings interface (English / Russian).

Features

  • Flexible builder – method chaining with .WithColor(), .WithTag(), .WithLogType(), etc.
  • Tag system – each tag has its own color and name that can be edited.
  • Code generation – saving settings automatically creates TagType.cs and LogColor.cs.
  • Conditional compilation – all logging methods are stripped from release builds.
  • Console clearing – XLogger.ClearConsole() works only in the Editor.
  • ScriptableObject settings – all parameters are stored in LoggerSettings.asset, accessible via Tools/XLogger/Settings.
  • Localization – switch the settings UI language.
  • Correct double-click – clicking a log in the Console always opens the calling code.

Installation

Via .unitypackage (recommended)

  1. Download the latest release.
  2. Import the .unitypackage via Assets → Import Package → Custom Package.
  3. Done! The plugin will automatically create the settings file and show the welcome window.

Manual installation

  1. Copy the XLogger folder anywhere inside Assets.
  2. Reload Unity (or press Ctrl+R).
  3. Open the settings window via Tools → XLogger → Settings.

Quick Start

  1. Open the settings window
    Tools → XLogger → Settings
  2. Configure tags
    In the Tag Settings section add/remove tags and set their colors.
  3. Configure message colors
    In the Message Settings section choose color and style for Log, Warning, and Error.
  4. Add custom colors
    In the Color Settings section define your named colors (they will be available as LogColor.YourColor).
  5. Save
    Click Save Settings – TagType.cs and LogColor.cs will be generated.
  6. Use in code
    // Simple logs
XLogger.Log("Hello");
XLogger.LogWarning("Warning");
XLogger.LogError("Error");

// Flexible variant
XLogger.Message("Multi-line\nmessage")
    .WithColor(LogColor.Cyan)
    .WithFontStyle(FontStyle.Bold)
    .WithTag(TagType.INPUT)
    .WithLogType(XLogType.LogWarning)
    .Log();

// Conditional log
XLogger.Log("This will only appear if condition == true", condition);

Editor Settings

All settings are stored in the LoggerSettings.asset file, which is automatically created in the Resources folder next to the plugin.

You can edit it manually via the Unity Inspector or through the settings window.

Settings sections

  • Tag Settings – enable/disable tag display, default tag, list of custom tags.
  • Message Settings – colors and styles for Log, LogWarning, LogError.
  • Color Settings – list of named colors (name → color) that will be available in the LogColor structure.

API (for developers)

Main XLogger methods

// Simple methods
public static void Log(object message, bool condition = true);
public static void LogWarning(object message, bool condition = true);
public static void LogError(object message, bool condition = true);

// Extended methods (with context, color, style, tag)
public static void Log(object message, Object context, bool condition = true);
public static void Log(object message, Color32 color, bool condition = true);
public static void Log(object message, TagType tag, bool condition = true);
// ... and other combinations

// Builder for flexible configuration
public static MessageInfo Message(object message);

MessageInfo builder

XLogger.Message("text")
    .WithColor(Color32 color)                 // sets the color
    .WithFontStyle(FontStyle style)           // Normal/Bold/Italic/BoldAndItalic
    .WithTag(TagType tag)                     // sets the tag
    .WithLogType(XLogType type)               // Log / LogWarning / LogError
    .WithContext(Object context)              // context for highlighting in the Editor
    .WithCondition(bool condition)            // conditional output
    .Log();                                   // sends the message

Code generation

When you save the settings, the following files are automatically generated:

  • TagType.cs – enum of all tags (the first element is always LOGGER = 0).
  • LogColor.cs – structure with static Color32 properties for each color.

Build Behavior

  • All XLogger.Log* methods and Message(...).Log() are stripped from release builds (without DEVELOPMENT_BUILD). They work in the Editor and Development builds.
  • XLogger.ClearConsole() works only in the Editor.

Important: Logging is completely disabled in release builds. This is intentional for performance reasons.

Requirements

  • Unity 2020.3 or newer (tested on 2021.3 LTS, 2022.3, 2023.2).
  • Platform: any platform that supports the Unity Editor (Windows, macOS, Linux).
  • Dependencies: none.

Frequently Asked Questions

Q: Why don’t my logs appear in the build?
A: All logging methods are stripped by conditional compilation in release builds. This is done for performance.
Q: How do I add a new tag?
A: Open the settings window (Tools/XLogger/Settings), go to the Tag Settings section, click + in the Tags field, enter a name and choose a color. Click Save Settings – the tag will appear in the TagType enum.
Q: How do I add a custom color to LogColor?
A: In the settings window, go to the Color Settings section, add a new entry, set the name and color. After saving, a static property with that name will appear in LogColor.
Q: Why doesn’t the tag appear in the message?
A: Check that the Show Tag option is enabled in the settings (Tag Settings section). Also make sure you passed the tag via .WithTag().
Q: Can I use LogColor outside the logger?
A: Yes, LogColor is a regular structure with colors and can be used anywhere in your code.
Q: How do I switch the interface language?
A: At the top of the settings window there is a dropdown – select English or Русский. The choice is saved in EditorPrefs.
Q: Is there a conflict with UnityEngine.Logger?
A: No, XLogger is a unique name and does not conflict with Unity’s built-in logger.
Q: Why does double-clicking a log open the wrong file?
A: This issue was fixed in version 1.0.1. Make sure you are using the latest release. It is also recommended to enable Strip logging callstack in the Console window (⋮ → Strip logging callstack).
